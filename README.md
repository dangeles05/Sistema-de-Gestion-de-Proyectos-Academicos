# Sistema de Gestion de Proyectos Academicos
Repositorio oficial de el Departamento de Posgrado e Investigación y Subdirección de Posgrado e Investigación para la gestión y respaldo de el sistema que será entregado posteriormente a los administradores

## Cronograma de Actividades

| Periodo                                  | Actividades                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1er Bimestre** 01/06/2026 - 03/08/2026 | - Levantamiento de requerimientos del departamento.<br>- Análisis del problema actual de organización documental.<br>- Diseño de la estructura del sistema.<br>- Diseño de base de datos.<br>- Diseño de interfaz inicial.<br>- Configuración del entorno de desarrollo (ASP.NET MVC y SQL Server).                |
| **2do Bimestre** 04/08/2026 - 05/10/2026 | - Desarrollo del módulo de inicio de sesión.<br>- Desarrollo del módulo de registro de proyectos.<br>- Implementación de subida y almacenamiento de archivos PDF.<br>- Desarrollo del buscador de proyectos.<br>- Desarrollo de funciones de edición y eliminación.<br>- Integración con base de datos SQL Server. |
| **3er Bimestre** 06/10/2026 - 02/12/2026 | - Pruebas del sistema en red local.<br>- Corrección de errores y optimización.<br>- Implementación en equipo servidor del departamento.<br>- Capacitación básica al personal administrativo.<br>- Elaboración de documentación técnica y manual de usuario.<br>- Entrega final del sistema.                        |
